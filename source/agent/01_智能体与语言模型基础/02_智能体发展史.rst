
第二章 智能体发展史
====================

1. 符号主义（Symbolism）
----------------------------------------------

核心思想：通过人工定义的知识和逻辑规则实现智能。

- **物理符号系统假说**：认为符号处理是实现智能的基础。
- **专家系统**：由知识库和推理机组成，通过 IF-THEN 规则进行推理。
- **代表项目**：

  - MYCIN：基于规则的医疗诊断专家系统。
  - SHRDLU：能够理解自然语言并在积木世界中执行任务。
  - ELIZA：通过关键词匹配和文本替换模拟人类对话。

**局限性**：

- 知识需要人工编写，维护成本高。
- 缺少真正的语义理解和常识。
- 面对未知情况时缺乏灵活性。


2. 心智社会（Society of Mind）
----------------------------------------------------

马文·明斯基提出：复杂智能可以由多个简单智能体协作产生。

核心思想：

- **分工协作**：每个简单智能体只负责特定任务。
- **去中心化**：不依赖单一的中央控制器。
- **涌现（Emergence）**：简单个体通过相互协作产生复杂智能行为。

这一理论为后来的多智能体系统（Multi-Agent System）提供了重要启发。


3. 学习范式的演进
----------------------------------------

3.1 联结主义（Connectionism）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

核心思想：通过神经网络从数据中自动学习知识。

- 使用神经网络表示和处理信息。
- 通过训练调整网络权重。
- 典型技术：深度学习、Transformer。

**与符号主义的区别**：

- 符号主义：人工编写规则。
- 联结主义：从数据中学习规律。


3.2 强化学习（Reinforcement Learning）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

核心思想：智能体通过与环境交互，根据奖励反馈不断优化决策策略。

主要组成：

- Agent：智能体，负责执行决策。
- Environment：环境。
- State：环境状态。
- Action：智能体采取的行动。
- Reward：环境提供的奖励。
- Policy：根据状态选择行动的策略。

工作流程：

观察状态 → 选择行动 → 获得奖励 → 更新策略 → 重复

**核心目标**：最大化长期累积奖励，而不是单次即时奖励。

代表项目：AlphaGo，通过自我对弈不断优化下棋策略。


3.3 大语言模型（LLM）
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

核心思想：通过海量数据预训练，获取通用知识与语言处理能力。

关键技术：

- 预训练（Pre-training）：从海量数据中学习通用知识。
- 微调（Fine-tuning）：针对特定任务优化模型。
- 上下文学习（In-context Learning）：通过提示中的示例完成任务。
- 思维链（Chain-of-Thought）：通过分步推理处理复杂问题。

LLM 为现代智能体提供了知识理解、推理和规划能力。


4. 现代 LLM Agent
----------------------------------------

现代智能体以大语言模型为核心，结合多个功能模块完成复杂任务。

**核心组件**：

- LLM：负责理解、推理和决策。
- Memory：存储历史信息和上下文。
- Planning：拆解任务并制定执行计划。
- Tool Use：调用外部工具完成实际操作。
- Execution：执行具体行动。

**工作流程**：

感知（Perception）
    获取用户输入或环境信息。

思考（Thought）
    结合记忆与任务目标进行推理和规划。

行动（Action）
    调用工具或执行任务。

观察（Observation）
    获取执行结果，更新记忆并继续决策。

整个过程形成持续迭代的闭环。


5. 本章总结
----------------------------------

智能体的发展可以概括为：

1. **符号主义**：让机器按照预设规则进行推理。
2. **心智社会**：通过多个简单智能体协作产生复杂智能。
3. **联结主义**：让机器从数据中学习知识。
4. **强化学习**：让机器通过试错学习决策策略。
5. **大语言模型**：让机器具备更通用的知识和推理能力。
6. **现代 Agent**：融合 LLM、记忆、规划与工具，实现自主任务执行。

**核心理解**：

智能体的发展经历了从“人工编写规则”到“数据驱动学习”，
再到“以大模型为核心进行自主规划和执行”的演进过程。
