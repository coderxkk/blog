大语言模型基础：简明总结
========================================

1. 大语言模型在做什么
----------------------------------------

可以把它理解为“文字接龙高手”：根据前文预测下一个词元，反复生成，组成回答。它是智能体理解指令和生成内容的基础。

2. 技术如何发展
----------------------------------------

* **N-gram**：根据前面几个词做预测，难以处理陌生组合。
* **词向量**：把词变成数字，让模型学习词义之间的关系。
* **RNN、LSTM**：增加记忆能力，但按顺序处理，效率受限。
* **Transformer**：用注意力寻找上下文中的关联，便于并行训练。

注意力帮助模型抓重点，位置编码帮助它区分先后顺序。
Decoder-Only 架构则根据已有内容，逐步生成后续内容。

3. 怎样与模型沟通
----------------------------------------

提示词应说明任务、背景和输出格式，也可以提供示例。
指令调优让模型更善于按要求回答。

* **Temperature**：控制输出的随机程度。
* **Top-k、Top-p**：限制生成时的候选范围。
* **Token**：文本切分后的单位，影响长度限制和费用。

4. 怎样使用和选择模型
----------------------------------------

文章演示了本地运行开源模型：加载模型、编码输入、生成结果、解码成文字。

选型要综合考虑能力、费用、速度、上下文长度和部署条件。
API 使用方便，本地部署更便于自主控制，但需要硬件和维护。

5. 模型有哪些局限
----------------------------------------

增加参数、数据和算力通常能改善表现，但三者需要合理配合。

模型可能编造事实，也可能知识过时或带有偏见。
检索资料、调用工具和核验结果，可以提高可靠性。
