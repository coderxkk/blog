第四章：智能体经典范式构建
============================================================

核心内容
------------------------------------------------------------

智能体把大模型、工具和工作流程连接起来，完成任务。
本章用 Python 从零实现三种做事方式，帮助读者理解框架背后的原理。

三种范式怎么理解
------------------------------------------------------------

ReAct：边做边调整
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

先判断下一步，再调用工具，根据返回结果继续行动，直到完成任务。
例如：搜索手机信息，再整理答案。适合需要外部信息、过程不确定的任务。

流程::

   思考 -> 行动 -> 观察结果 -> 决定下一步

Plan-and-Solve：先列计划，再逐步完成
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

先把问题拆成步骤，执行时利用前面步骤的结果。
例如：分别计算每天的销量，再求总和。适合步骤清楚的多步任务。
本章实现的计划是固定的，遇到变化需要另外设计重新规划机制。

流程::

   拆分任务 -> 制定计划 -> 按顺序执行 -> 得到答案

Reflection：做完后检查和修改
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

先生成初稿，再找问题、提建议、修改，并保存尝试和反馈。
例如：检查查找素数的代码，换用更高效的算法。
它有助于改善质量，但增加调用费用和等待时间。

流程::

   生成初稿 -> 检查问题 -> 根据反馈修改 -> 再次检查

实现时要抓住什么
------------------------------------------------------------

* 统一封装模型调用，配置好密钥和服务地址。
* 为工具提供名称、用途说明和执行函数。
* 约定输出格式，保存历史结果，处理解析和调用失败。
* 设置结束条件和次数上限，避免无限循环。

怎样选择
------------------------------------------------------------

* 需要边查边做：ReAct。
* 需要有序完成多个步骤：Plan-and-Solve。
* 需要反复打磨结果：Reflection，也可以叠加在前两者之上。
